# Other modules

The rest of tkinter's modules, each imported on its own as in tkinter:
`from tkcurses import font`.

The last two are not tkinter's at all: [curses](curses.md) and
[panels](panel.md) are the standard library's `curses` and
`curses.panel`, drawn on the same screen as the widgets, so one program
can use both.
